Este repositório descreve o desenvolvimento da primeira fase de um jogo narrativo interativo em Java, mais especificamente um Role-Playing Game (RPG) intitulado “O Show Tem de Continuar”. O objetivo principal dessa primeira etapa foi compreender os princípios da Programação Orientada a Objetos (POO), entender como modelar o jogo com base no padrão de arquitetura de software Model-View-Controller (MVC) e aprender a analisar as menores partes testáveis de um programa através de testes de unidade. O projeto foi feito com a linguagem de programação Java através do ambiente de desenvolvimento integrado IntelliJ IDEA.
